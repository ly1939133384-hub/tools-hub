📖 使用说明（点开看）

一句话：已知红色物品的格数种类和平均格数（红均数），反推所有可能的物品个数与组合。

第一步：填"格子数"（有哪些格数的物品，重复自动去重，如 1,2,2,3,5 按 1,2,3,5 算）。
第二步：填"红均数"（百分位直接舍去，如 2.56 按 2.5 算）。
第三步：看分组统计——每行是"物品个数 n + 格子总和 + 平均验证 + 组合种数"，直接告诉你哪些 n 可能、每种多少组合。
第四步：逐步加约束收敛（红色物品数 ≤/=/≥、格子总数 ≤/=/≥、存在 X 格的物品 Y 个、1 格物品个数），候选 ≤50 自动展开明细。
第五步：唯一解会绿色高亮横幅提示；"📋 复制全部"可一键复制答案。

🎯 示例动线（按图走一遍）

题目：格数 1,2,3,4,6,8,9,12,15,16，红均数 4.6，物品数小于 8（可重复），求可能的组合。

① 填数：格子数填 1,2,3,4,6,8,9,12,15,16，红均数填 4.6。
② 看统计：立刻出 n=3（总和14，平均≈4.67→4.6）共7种、n=5（总和23）共36种、n=6（总和28）共78种；n=1,2,4,7 自动跳过（平均数夹不住整数，无解）。
③ 加约束：选"红色物品数 ≤ N"填 7 → 只剩 n=3/5/6 共 121 种。
④ 锁死：选"红色物品数 = N"填 3 → 只剩 n=3 的 7 种明细：1+1+12、1+4+9、2+3+9、2+4+8、2+6+6、3+3+8、4+4+6。
⑤ 抄答案：点"📋 复制全部"发给你朋友。
